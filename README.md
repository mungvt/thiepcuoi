# Thiệp cưới online

Thiệp mời cưới dạng web một trang (HTML/CSS/JS thuần, không cần build).

## Chỉnh sửa
Mọi thứ nằm trong `index.html`:
- `WEDDING` – ngày giờ cưới dùng cho đồng hồ đếm ngược
- `PHOTOS` – danh sách ảnh album
- Hộp quà: thay ảnh QR, ngân hàng, số tài khoản trong modal `#mGift`

## Xem trên máy
Mở trực tiếp `index.html` bằng trình duyệt.
